# Calculator Web Application – CodSoft Internship Project

I am pleased to present my recent project, a fully functional Calculator Web Application  developed using HTML, CSS, and JavaScript as part of my CodSoft Web Development Internship.

This project focuses on building a simple yet interactive calculator that performs basic arithmetic operations while maintaining a clean and user-friendly interface.

# Key Features:

* Supports basic arithmetic operations (+, −, ×, ÷)
* Clean, modern, and intuitive user interface
* Responsive layout using CSS Grid and Flexbox
* Interactive functionality using JavaScript event handling
* Real-time expression evaluation

Through this project, I strengthened my understanding of:

* DOM manipulation
* Event-driven programming
* Core JavaScript logic implementation
* UI/UX design principles for web applications

This project helped me enhance my frontend development skills and gave me practical experience in building interactive web applications. I look forward to continuing to learn and build more such projects.
